
1. Проверка процессора, материнской платы и вентиляторов
Установите пакет lm-sensors, который отвечает за чтение аппаратных датчиков:
```bash
sudo apt update && sudo apt install lm-sensors -y
```

Запустите автоматическое определение доступных датчиков в системе (на все вопросы скрипта нажимайте ENTER, чтобы согласиться по умолчанию):
```bash
sudo sensors-detect
```

Выведите текущие показатели температуры, напряжения (Vcore) и оборотов вентиляторов (RPM):
```bash
sensors
```

2. Проверка температуры NVMe SSD-накопителей
Если у вас установлены современные SSD-диски формата NVMe, их температура часто отображается через отдельную утилиту:
```bash
sudo apt install nvme-cli -y
sudo nvme smart-log /dev/nvme0
```
(Замените /dev/nvme0 на имя вашего диска, если их несколько).

3. Проверка видеокарты (GPU)
Для карт NVIDIA (потребуются установленные проприетарные драйверы):
```bash
nvidia-smi
```

Для карт AMD / Intel:
```bash
sudo apt install radeontop intel-gpu-tools -y
```
# Для AMD:
```bash
sudo radeontop
```
# Для Intel:
```bash
sudo intel_gpu_top
```
