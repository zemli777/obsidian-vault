## Состав набора

| Плагин          | Назначение                                  |
| --------------- | ------------------------------------------- |
| Dataview        | Динамические списки и таблицы по заметкам   |
| Templater       | Автоматическое заполнение новых заметок     |
| Tasks           | Задачи, сроки и повторения                  |
| Calendar        | Навигация по ежедневным заметкам            |
| Git             | История изменений и резервное копирование   |
| Omnisearch      | Быстрый полнотекстовый поиск                |
| QuickAdd        | Быстрое создание заметок и запуск сценариев |
| Style Settings  | Настройка внешнего вида                     |
| Advanced Tables | Редактирование Markdown-таблиц              |
| Excalidraw      | Диаграммы и визуальные заметки              |

После установки перезапустите Obsidian и убедитесь, что плагины включены в разделе **Настройки → Сторонние плагины**.

## Dataview

Добавьте свойства в начало заметки:

```yaml
---
type: project
status: active
priority: high
created: 2026-08-20
tags: [project, obsidian]
---
```

Список активных проектов:

````markdown
```dataview
LIST
FROM #project
WHERE status = "active"
SORT file.name ASC
```
````

Таблица проектов:

````markdown
```dataview
TABLE status AS "Статус", priority AS "Приоритет", created AS "Создан"
FROM #project
SORT created DESC
```
````

Dataview автоматически обновляет результаты при изменении заметок.

## Templater

Создайте папку `Templates` и укажите её в **Настройки → Templater → Template folder location**.

Шаблон заметки:

```markdown
---
type: note
created: <% tp.date.now("YYYY-MM-DD") %>
tags: []
---

# <% tp.file.title %>

## Краткое содержание

## Основная информация

## Связанные заметки

- [[]]

## Источники
```

Применение: `Ctrl+P → Templater: Insert template`.

## Tasks

Обычная задача:

```markdown
- [ ] Подготовить документацию
```

Задача со сроком и задача с повторением:

```markdown
- [ ] Подготовить документацию 📅 2026-08-25
- [ ] Сделать резервную копию 🔁 every week 📅 2026-08-24
```

Общая страница задач:

````markdown
# Задачи

## Просроченные

```tasks
not done
due before today
sort by due
```

## На сегодня

```tasks
not done
due today
```

## Ближайшие

```tasks
not done
due after today
sort by due
limit 20
```
````

## Calendar

В разделе **Настройки → Ежедневные заметки** задайте:

```text
Папка: Journal/Daily
Формат даты: YYYY-MM-DD
Шаблон: Templates/Ежедневная заметка
```

Пример ежедневной заметки:

```markdown
---
type: daily
date: <% tp.date.now("YYYY-MM-DD") %>
tags: [daily]
---

# <% tp.date.now("DD.MM.YYYY") %>

## План
- [ ]

## События

## Заметки

## Итоги дня
```

Щелчок по дате в Calendar открывает или создаёт ежедневную заметку.

## Obsidian Git

Откройте терминал в каталоге vault:

```bash
cd "/путь/к/vault"
git init
git add .
git commit -m "Initial Obsidian vault"
```

Рекомендуемый `.gitignore`:

```gitignore
.obsidian/workspace.json
.obsidian/workspace-mobile.json
.trash/
.DS_Store
```

В настройках Obsidian Git можно включить commit-and-sync каждые 30 минут и pull при запуске. Не помещайте пароли и токены в публичный репозиторий. Git не заменяет полноценное резервное копирование.

## Omnisearch

Запуск: `Ctrl+P → Omnisearch: Vault search`. Удобно назначить сочетание `Ctrl+Shift+F`.

Ищите по названию технологии, фразе из текста, имени проекта или номеру ошибки. Плагин полезен, когда содержание заметки известно, а имя файла и папка забыты.

## QuickAdd

Откройте **Настройки → QuickAdd → Manage Choices** и создайте команду:

```text
Название: Новая идея
Тип: Template
Шаблон: Templates/Заметка.md
Папка: 00 Inbox
```

Включите значок молнии рядом с командой. После этого она появится в палитре команд. Создайте аналогичные команды для проекта, встречи, контакта и технической заметки.

## Style Settings

Откройте **Настройки → Style Settings**. Доступные параметры зависят от темы: шрифт, ширина заметки, цвета заголовков, ссылки, фон и блоки кода. Если раздел пуст, текущая тема не предоставляет настроек.

## Advanced Tables

Плагин выравнивает Markdown-таблицы и упрощает навигацию:

```markdown
| Проект      | Статус   | Срок       |
| ----------- | -------- | ---------- |
| База знаний | В работе | 2026-09-01 |
| Сервер      | Готово   | 2026-08-15 |
```

- `Tab` — следующая ячейка;
- `Enter` — новая строка;
- команды палитры — форматирование и сортировка.

## Excalidraw

Создание рисунка: `Ctrl+P → Excalidraw: Create new drawing`.

Добавляйте текст, блоки, стрелки, изображения и ссылки на заметки. Текст `[[Название заметки]]` превращает элемент схемы в ссылку Obsidian. Excalidraw подходит для архитектуры системы, карты проекта, бизнес-процесса и мозгового штурма.

## Рекомендуемый рабочий процесс

1. Сохраняйте идеи через QuickAdd в `00 Inbox`.
2. Создавайте оформленные заметки через Templater.
3. Добавляйте свойства, теги и внутренние ссылки.
4. Ведите сроки через Tasks, а ежедневные записи — через Calendar.
5. Собирайте обзоры через Dataview.
6. Ищите информацию через Omnisearch.
7. Рисуйте сложные связи в Excalidraw.
8. Сохраняйте историю изменений через Git.
